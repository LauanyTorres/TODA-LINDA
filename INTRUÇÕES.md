Crie uma landing page editorial responsiva para a marca TODA LINDA STORE, especializada em biquínis. O site deve funcionar como uma pequena revista digital / lookbook, e não como uma loja completa. O objetivo é apresentar os modelos, mostrar os preços e direcionar a cliente para contato via WhatsApp, Instagram ou e-mail.

Não inclua: carrinho de compras, checkout, login, painel administrativo ou banco de dados.

Stack recomendada:

Fase 1 (GitHub Pages): HTML5 + Tailwind CSS via CDN + JavaScript puro.

Fase 2 (Vercel): opcionalmente migrar para Next.js + Tailwind CSS.

Não usar: Kotlin, Java, Flutter ou Bootstrap.

Use Google Fonts para tipografia e Lucide Icons ou Font Awesome para ícones.

Requisitos de responsividade para Android:

Projete mobile-first.

Inclua <meta name="viewport" content="width=device-width, initial-scale=1.0">.

Use Flexbox e CSS Grid para os cards dos biquínis.

Use unidades relativas: rem, %, vw, clamp().

Botões grandes e fáceis de tocar.

Imagens em .webp, com loading="lazy" e alt descritivo.

Teste no Chrome do Android e no modo responsivo do navegador.

Estilo visual:

Feminino, praiano, elegante, moderno, clean e editorial.

Paleta sugerida: tons de areia, branco, dourado, coral ou verde-água.

Estrutura em página única:

Hero: nome da marca, slogan, imagem de destaque e botão “Fale conosco”.

Coleção / Catálogo: grid ou masonry com fotos dos biquínis, nome do modelo, preço e botão “Tenho interesse” ou “Comprar pelo WhatsApp”.

Sobre a marca: texto curto e humanizado.

Contato: botões para WhatsApp, Instagram e e-mail.

Rodapé: direitos autorais e redes sociais.

Imagens:

As imagens dos biquínis estão na pasta assets.

Use caminhos relativos, por exemplo: assets/nome-da-imagem.jpg.

Adicione alt descritivo, loading="lazy" e tamanhos responsivos.

Funcionalidades:

Botões de contato clicáveis com target="_blank" e rel="noopener".

Preços visíveis nos cards.

Layout responsivo para celular, tablet e desktop.

SEO básico: title, meta description e Open Graph.

Código limpo, semântico e acessível.

Deploy:

O site será publicado primeiro no GitHub Pages e depois na Vercel.

Inclua um README.md com instruções de publicação.

Se migrar para Next.js, siga a estrutura da Vercel.

Entregáveis:

index.html

Tailwind via CDN (ou style.css, se preferir)

script.js (se necessário)

README.md

Uso correto da pasta assets
